ABOUT

Dwarfworks

Credits

Primarily developed by ChatGPT 6 Astra and ChatGPT 5.6 Sol, with some help from Fable 5.1. Design and orchestration by Stephen Barnes.

Inspirations

Inspired by Roody:2d and Infinifactory. If you enjoy building machines here, we recommend both games.

Technical details

Built in TypeScript with plain HTML and CSS, without a UI framework. Canvas 2D draws the board and its procedural tiles; Vite builds the browser application.

The simulation advances in deterministic, discrete ticks: components observe the board, competing actions are resolved, and changes commit together. Welded tiles move as rigid bodies, while signed-ternary circuits carry negative, neutral, or positive charge. Animation draws between committed states.

Browser storage keeps your designs and progress locally.

Successful puzzle scores are submitted to a server so we can have histograms. No email or login is required.
