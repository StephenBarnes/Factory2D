ABOUT

Factory 2D

Credits

Primarily developed by ChatGPT 5.6 Sol and ChatGPT 6 Astra, with some help from Fable 5.1. Design and orchestration by Stephen Barnes.

Inspirations

Inspired by the block-built machines of Roody:2d and the factory puzzles of Infinifactory. If you enjoy building machines here, we recommend both games.

Under the hood

Built in TypeScript with plain HTML and CSS, without a UI framework. Canvas 2D draws the board and its procedural tiles; Vite builds the browser application.

The simulation advances in deterministic, discrete ticks: components observe the board, competing actions are resolved, and changes commit together. Welded tiles move as rigid bodies, while signed-ternary circuits carry negative, neutral, or positive charge. Animation only draws between committed states; it never changes the physics.

Rune arrays contain nested boards using the same simulation. Browser storage keeps your designs and progress locally. Vitest checks simulation behavior, and Playwright exercises browser workflows.
